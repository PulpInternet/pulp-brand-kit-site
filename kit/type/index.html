Type

Rules

ID Scope Checked by Rule
R-TYPE-12 house layout Every piece of text is set in a --f- family at a --t- size, at every width and in every mode. Nothing falls back to a system or host font.
R-TYPE-01 house lint Faces by position: typodojo, Typo Display and Recursive Sans Casual; Pulp, Libre Franklin; Thinkwell, Albert Sans and Instrument Sans. Arial is the only fallback.
R-TYPE-02 house lint No italics in any title, headline, lockup, label or display type, including single accent words.
R-TYPE-03 house lint Case by position: typodojo headlines are lowercase; Pulp heroes are caps and headings sentence case; Thinkwell is sentence case everywhere.
R-TYPE-04 house lint No monospace, except typodojo's Mono Casual for code and keys, opted in one spot at a time.
R-TYPE-05 house layout Every piece of text has a role, and the role decides its size, line height and what it does when it runs long.
R-TYPE-06 house lint Uppercase labels are tracked 0.1 to 0.16 em at weight 600 (500 in Recursive).
R-TYPE-07 house review Headline endings by position: typodojo always ends on a period; Pulp ends statements on a period; Thinkwell UI titles take none.
R-TYPE-08 house review Numbers in tables, meters and data use tabular figures.

Contract

From pack/contracts.ts.

type FaceName = 'Libre Franklin' | 'Albert Sans' | 'Instrument Sans'
              | 'Typo Display' | 'Recursive Casual';

type TextRole = 'display' | 'hero' | 'heading' | 'title' | 'subhead'
              | 'body' | 'label' | 'caption' | 'number' | 'tick';

type TextSpec = {
  role: TextRole;
  face: FaceName;                // from the property's position
  weight: 400 | 500 | 600 | 700 | 800;
  size: { desktop: number; tablet: number; phone: number };
  lineHeight: number;
  case: 'lower' | 'sentence' | 'upper';
  trackingEm?: number;           // labels 0.1 to 0.16
  whenLong: 'wraps' | 'clamp-2' | 'clamp-3' | 'truncate-1' | 'never';
  tabular?: true;                // numbers
  italic: false;                 // always
};
